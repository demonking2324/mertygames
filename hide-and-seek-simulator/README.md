## Hide & Seek Simulator – Menu Prototype

This is a small HTML/CSS/JS prototype for the **Hide & Seek Simulator** main menu.

It currently supports:

- **Main menu** with buttons for `Offline`, `Online`, and `Settings`
- **Simple screen switching** between the three sections
- **Placeholder content** for each screen so we can hook real game logic later

### How to run

- **Option 1 – Double click**
  - Open `index.html` in your browser (Chrome, Edge, Safari, etc.).

- **Option 2 – Local dev server (recommended)**
  - In the project folder, run:

```bash
npm install
npx serve .
```

  - Then open the printed URL (usually `http://localhost:3000` or similar).
